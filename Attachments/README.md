# 项目随附素材

此目录随 Debug、Release 和发布包复制。启动读取 `libraries.json`，在用户选择的客户端图库之外注册随附的 Crystal v2/v3 `.lib`，复用同一解码器、缓存和预览流程。

当前清单为空：天宫、海底、异星的新位图尚未生成，现有主题仍使用原生图库。不能将此目录当作已完成的三套内置美术资源。

每个正式资源包应保留 PNG 源文件和切片、锚点说明，将可运行素材打包为 `.lib`，再在清单中添加 `id` 和相对此目录的 `file`。例如条目格式为 `{ "id": 400, "file": "celestial/scene.lib" }`；400 仅作示例，实际编号须与目标客户端和地图格式确认。编号冲突会拒绝加载，不覆盖用户图库。缺少清单时兼容旧版本；清单列出但缺失或损坏的图库会报告加载错误。

PNG 源文件不直接用于地图渲染。地图仍保存图库编号和图片索引；交付游戏客户端时也必须安装配套图库并配置相同编号。此功能没有改变各客户端对图库编号的限制，也不替代客户端资源安装。

三套美术规格与提示词见 [设计文档](../docs/theme-art/ART_DIRECTION.md)。

# 制作模块与生成模块地图

模块工作流为：**框选地图区域 → 制作模块并编辑接口 → 保存入库 → 自动生成模块地图**。

也可以批量制作：**选择 `.map` → 调整分块并预览 → 所选模块入库 → 随机生成新地图**。“工具”菜单中的模块分组现在包含“从选区生成模块”“从地图批量拆分模块”和“自动生成模块地图”。

独立“拼接模块”菜单和双模块窗口已删除。生成地图继续使用原有放置、连通校验和整体撤销能力；城镇、地牢、省域等专用生成器仍各自独立。

## 从地图选区制作模块

1. 打开地图，按 `M` 切换选择工具，拖出矩形选区。范围至少 2×2 格、最多 100 万格，单边不超过 4096 格，至少包含一个有内容的格子。
2. 点击 **工具 → 从选区生成模块**。采集选区内所有图层及碰撞，保留边缘空白，不移动或删除源地图内容。
3. 在同一窗口填写名称、查看素材和编辑接口。左侧列表选择接口，中央直接在素材画布上操作，右侧修改属性；不再打开嵌套编辑弹窗。
4. 确认接口及内部连通性后点击 **保存模块入库**。只有至少启用一个合法接口，且模块内所有可行走格互通时才允许保存。
5. 点击 **工具 → 自动生成模块地图**，在模块列表中使用刚保存的模块。生成器会创建独立新地图，无需先打开空白地图或取消原选区。

自动检测以边界格和向内一格均无碰撞为依据，不根据墙壁图片推断通路。连续通路合并后按最大 64 格拆分，北／南边界优先占用可行走角点。超过 64 个候选时全部保留，需要减少启用数量。

空白格按可行走处理；取消启用某个接口不会自动补墙或封路。含地面素材时建议选择偶数宽高，并保证相对接口的地面网格相容。通过内部连通校验不代表能满足任意模块池、数量或区域的生成要求。

## 从 .map 批量拆分模块

1. 点击 **工具 → 从地图批量拆分模块**，选择一个 `.map` 文件。按当前素材格式读取独立副本，不切换或修改正在编辑的地图，也不覆盖源文件。
2. 选择 **固定网格** 或 **按通道拆分**，填写 4～512 的偶数宽高，点击 **预览拆分**。按通道模式将宽高作为参考，优先在窄、平直的通路横截面切分，并用完整四邻域碰撞验证结果；不会依据外观自动识别建筑。
3. 左侧展示素材缩略图、位置、尺寸、接口数量和候选类型；类型仅根据接口方向提供建议。画布上点击模块可与列表联动，勾选框只决定是否入库。绿色表示主通路，橙色编号表示其他连通区域，红色背景表示阻挡；可关闭通行覆盖或开启网格。
4. 顶部通行区域列表可以定位主通路或孤立区域；“定位问题”聚焦当前模块的错误坐标。按通道模式首次聚焦主通路，“适应画面”恢复整图视野。
5. 使用 **添加竖向切线／添加横向切线** 在块内点击或拖动。切线吸附两格地面网格，橙色虚线及 A/B 标记预览双侧开口。松开后校验新模块和邻居；错误以红色草稿和原因保留，按 `Esc` 取消，不能带着错误草稿入库。
6. **移动切线** 拖动两个矩形之间的完整公共边；T 形交接需先合并。**合并模块** 依次点击两个相邻模块，合并后必须仍是矩形，不得吞入第三个块。**保护区域** 可反向拖动框选；自动及手动切线避开保护区与有实例元数据的对象。保护范围跨已有切线时需合并或重新预览，不能直接保存。
7. 支持局部撤销／重做、`Ctrl+Z`／`Ctrl+Y`／`Ctrl+Shift+Z`；文本框快捷键保留文本编辑含义。一次拖动对应一条历史操作，失去指针捕获则取消未完成拖动。滚轮缩放，中键或空格拖动画布，操作不改原图素材或碰撞。
8. 填写前缀，点击 **所选模块入库** 或 **入库并随机生成**。名称采用“前缀-序号”；后者仅使用本批模块，生成预览后点击 **创建新地图**。生成数量指实例数，同种模块可重复使用。

每次最多 256 块，源图不超过 400 万格；候选完整覆盖源图，不重叠、不漏格。固定网格的一格余数并入前块；通道搜索受深度和候选数限制，目标大小不保证严格满足。无法细分的区域保留并说明问题，不能通过抹掉小岛或填碰撞强行通过。局部历史最多保留 16 次操作，并按保存的格子数限制内存，至少保留最近一次操作。

只有包含内容、内部连通且有有效配对接口的模块可以入库。所有接口共享边界和向内一格的校验，地图外缘不自动产生接口；保留空白格可通行语义。不自动封口、补墙或旋转，因此随机结果的素材接缝及未使用出口仍需设计者检查。

参数修改、分析失败或取消保留上一次画面供参考，并禁用过期结果保存。重新拆分保留未改变矩形的勾选状态；局部切分、合并及撤销同步重算邻居接口。批量保存一次提交目录，中途失败或取消回滚本批新增文件，不覆盖已有模块或源图。

## 在画布上编辑连接点

- **选择**：点击画布接口或左侧条目，列表、属性和画布同步。选中接口显示青色粗边框、方向箭头和端点。列表勾选框只控制是否启用，不改变当前编辑对象。
- **新增**：点击“新建连接点”后出现带编号的临时标记及操作提示。点击边界创建一格接口；沿同一边拖动设置宽度，支持反向拖动。默认类型为 `path`，编号自动避重；角点默认北／南方向，可在右侧调整。
- **移动和调整宽度**：选中后拖动接口主体移动，拖动端点调整宽度，位置沿所属边界变化。一格接口的两个端点分别显示在两侧。
- **属性编辑**：类型、方向、宽度修改即时显示；高级坐标中可直接修改 X／Y。离开输入框、切换条目或应用时提交合法修改，一次编辑作为一条历史操作。
- **错误反馈**：草稿以橙色虚线显示，非法草稿变红。越界、重叠和碰撞分别给出原因，重叠及碰撞标出坐标。非法输入不会因切换条目而丢失，必须修正或按 `Esc` 取消。
- **启用状态**：普通接口绿色，未启用接口灰色虚线，未启用接口仍可选择和修改。只有已启用接口进入保存结果；未启用条目仅在本次编辑会话中保留。
- **撤销与取消**：删除按钮或 `Delete` 删除当前接口；`Ctrl+Z` 撤销，`Ctrl+Y`／`Ctrl+Shift+Z` 重做。`Esc` 放弃当前草稿，失去鼠标捕获时取消未完成拖动。文本框中的删除、撤销遵循文本编辑行为。
- **观察画面**：滚轮以鼠标位置为中心缩放，中键或空格拖动画布，“适应画面”恢复整体视图；可开关网格和碰撞。无素材库时显示格子示意图，接口编辑操作相同。

画布操作只改变接口元数据，不绘制或移动地图素材。取消整个窗口不写入目录。

## 编辑已有 .X 对象

双击素材对象，点击对象编辑区的“模块连接点”，使用相同的画布编辑组件。点击“应用”后回到对象编辑器，再按 `Ctrl+S` 保存对象和目录。

已有对象允许删除或禁用全部接口；清空后不再出现在自动生成模块列表中。即使对象内容已被全部擦除，也可以删除旧接口后保存。

## 自动生成模块地图

1. 加载素材库，打开 **工具 → 自动生成模块地图**。生成在独立空白地图上进行，原地图内容、选区和图层锁不参与生成。
2. 根据缩略图、名称、占地尺寸和接口摘要勾选模块。悬停条目查看文件路径；搜索支持名称、标签和接口类型，过滤不会取消隐藏条目的勾选。“选择搜索结果／取消搜索结果”只影响当前搜索结果，总选中数始终显示。
3. 设置数量（2～128）、种子和布局：链式沿最新模块延伸，分支优先从靠近起点的模块扩展，紧凑优先使用附近接口。填写参考宽度／高度（正整数，默认 256×256）。程序结合模块占地和生成数量估算初始尺寸，必要时尝试更大或更长的地图；过大的参考值会归一化。最终单边为 16～4096，总格数不超过 100 万。生成数量指放置的实例数，不要求勾选同样多的模块种类。
4. 点击“生成连通布局”。生成中显示活动指示和停止按钮，不显示没有依据的百分比。支持 1～256 种模块，同种模块可重复出现。
5. 预览顶部显示参考尺寸与实际新地图尺寸；参考输入不会被实际值覆盖。直接在素材画面中检查结果：滚轮缩放，中键／空格平移，开关模块边界和连接位置。点击模块实例查看编号、来源和接口信息。
6. 预览就绪后点击“创建新地图”，在新标签页打开生成结果，随后可按 `Ctrl+S` 保存。整次生成是一条历史操作，`Ctrl+Z` 撤销为同尺寸空白地图，`Ctrl+Y` 恢复布局。原地图内容、选区、图层锁和编辑历史保留；取消或生成失败不会新增标签页。

修改参数后，旧预览保留并标记过期，不能应用。生成失败或取消同样保留旧画面供参考；旧结果不会作为本次结果写入。文件或接口错误会选中问题模块，显示接口编号及可定位坐标。

未能放下目标数量时显示请求数量和本次最佳数量，可更换种子、扩大区域、减少数量或补充匹配接口；有界搜索失败不证明绝对无解。只有精确达到目标数量并通过整体连通性检查，才能应用。

尺寸估算使用完整占地（含空白边缘和负局部坐标），按偶数格对齐。程序在有限次数内尝试尺寸调整；即使采用最小模块也超过总格数上限时，会提示减少数量或选用更小模块。当前流程使用独立空白地图，不会再因截取模块的原选区已有内容而拒绝生成。

如果提示没有匹配接口，请在模块编辑器中检查方向、类型和宽度。例如北向 `path ×5` 需要南向 `path ×5`，不能连接南向 `path ×7`。自动识别只提供开口建议，不保证模块之间可匹配；此时更换种子无效。达到搜索次数上限则只说明本轮未找到布局，不应当作区域绝对无解。

## 校验、存储与兼容

- 每个模块最多启用 64 个接口，单个宽度 1～64 格。北／南接口向右延伸，东／西向下延伸；类型及宽度一致、方向相对才能匹配。
- 坐标使用 `.X` 局部坐标，可为负数。旧对象按非空格包围矩形确定边界；选区模块使用额外占地，防止空白边缘被裁掉。内容扩展时取占地与实际内容的并集。
- 开口及向内一格必须可行走，不能越界或重叠。模块内部和最终生成范围均按四邻格验证，不能借用范围外空白绕路，也不将对角接触视为连通。
- 生成区域上限 100 万格，模块池总占地上限 400 万格。放置不得覆盖已有内容、与其他模块占地重叠或破坏地面网格。
- 截取模块增加可选的 `connections.mapGroundGrid: true`，记录源地图偶数地面网格，区别于旧对象按图片坐标推断对齐方式。目录版本仍为 1，旧记录无需迁移，`.X` 字节格式及 `footprint` 结构不变。这个字段是放置语义，不是界面状态；旧对象没有该字段时继续使用原有对齐行为。
- 保留旧地图非绘制格的图片引用和所有碰撞位，不通过删除图片引用“修复”兼容性。模块缩略图与主画布采用同样的地面格规则，裁剪平移后渲染保持一致。
- 接口仍保存在 `catalogue/palette.json` 的 `connections` 中，选区范围仍使用可选 `footprint`；`.X` 文件格式不变。选中、高亮、草稿和撤销历史不写入目录。
- 保存时裁剪居中，接口和占地同步平移。入库采用新的独立文件名，同名模块可并存；保存失败、取消、源地图变化或目录冲突时回滚本次新文件，保留原内容。
- 分享模块需同时携带 `.X` 和目录记录；仅复制 `.X` 不包含接口及空白边距。

本轮没有增加图片旋转、权重、固定起终点、自动封闭出口或手工连续搭建。后续手工修改已放置实例不会自动维护连接网络，需要重新检查通路。

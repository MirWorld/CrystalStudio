# 自定义模块连接点

项目已经有城镇、地牢、省域、墙体和河岸生成能力。本功能补充“从地图选区制作模块 → 识别并确认连接点 → 保存入库 → 自动生成模块地图”的完整流程，也支持任意 `.X` 对象的连接点编辑和双模块手动拼接。现有城镇／地牢等专用生成器保持独立。

## 从地图选区制作模块（推荐入口）

1. 打开已有地图，按 `M` 切换选择工具，拖出一个矩形选区。选择至少 2×2 格、最多 100 万格，单边不超过 4096 格；选区至少包含一个有内容的格子。
2. 点击 **工具 → 从选区生成模块**。采集选区内所有图层的单元格及碰撞信息，不移动或删除源地图内容；选区边缘的空白格也会保留为模块占地。
3. 填写模块名称，检查“地图预览”和“连接示意图”。地图预览需要加载游戏素材库；连接示意图无需素材库，蓝色为有内容格、红色为碰撞、绿色为接口。
4. 勾选需要保留的自动识别接口，或点击“编辑模块连接点…”调整位置、方向、类型和宽度。识别依据是边界格及向内一格均无碰撞；空白格视为可行走，程序不会根据墙壁图片推测通路。
5. 点击 **保存模块入库**。只有选择 1～64 个合法接口且模块内部所有可行走格互通时才能保存。若无法保存，根据提示修改选区、碰撞或连接点；内部隔断需返回地图修正，再重新框选。
6. 新建或打开空白地图，点击 **工具 → 自动生成模块地图**。刚保存的模块会出现在模块池中，可与其他同类型、同宽度、相对方向的接口连接。

连续边界通路按最大 64 格拆分，北／南边界优先占用可通行角点，东／西边界不再重复；超过 64 个候选时全部展示，需要手动减少勾选。取消勾选只是不把该通路声明为接口，不会自动补墙或封路。自动识别默认类型为 `path`。

包含地面素材时建议使用偶数宽高的选区，并确认两端接口的地面网格相容。保存前检查内部连通性，不保证某个模块池能满足任意数量或区域的拼接要求；只有单端出口的模块也可作为终端模块入库。

入库使用独立的新文件名，显示名称不会变成文件路径。同名模块可并存，不覆盖已有对象。取消预览不写入；保存失败、地图版本过期或目录并发变化时回滚本次新文件。保存过程中关闭窗口会先等待保存／取消结果，再刷新主窗口目录。

## 编辑已有 .X 模块连接点

1. 双击素材列表中的 `.X` 对象，或新建对象并绘制内容。
2. 点击对象编辑区上方的“模块连接点”。
3. 在左侧单元格示意图点击边界位置，填写连接点编号、连接类型、方向和宽度。示意图中的蓝色代表有内容的格子，红色代表碰撞，绿色代表已添加的开口；这里不是素材图片预览。
4. 点击“添加／更新”保存当前条目，然后可以选择其他条目或点击“新建连接点”。“应用”会一并保存当前表单中的修改。切换条目前请先点击“添加／更新”。
5. 点击“应用”回到对象编辑器，再按 `Ctrl+S` 保存对象及目录。“取消”会放弃本次弹窗内的修改。

选择列表条目后可修改或删除；要清空全部连接点，逐个删除后应用并保存。即使对象内容被全部擦除，也可以打开此窗口清空旧连接点。

## 拼接两个模块

1. 分别为两个对象定义并保存连接点。例如，第一个对象在东边有宽度 2 的 `path` 开口，第二个对象在西边有宽度 2 的 `path` 开口。也可以选择同一个对象的两个实例，前提是有相对方向的连接点。
2. 切换到普通地图标签页，加载素材库并解锁图层，然后打开“工具 → 拼接模块”。
3. 选择第一个模块和连接点，再选择第二个模块；第二个连接点列表只显示方向相对、类型（不区分大小写）和宽度相同的条目。
4. 输入第一个模块的原点 X／Y，这是其局部坐标原点在目标地图中的位置，不是模块左上角。第二个模块原点会自动计算，使两个开口逐格相邻。
5. 点击“生成拼接预览”。“地图预览”显示素材和地图上下文；“连接示意图”显示占地、碰撞和两个绿色开口。
6. 确认后点击“应用到地图”，再按 `Ctrl+S` 保存地图。两个模块作为一次历史操作应用，`Ctrl+Z` 整体撤销，`Ctrl+Shift+Z` 重做。

预览不修改目标地图。修改模块、连接点或坐标后必须重新预览；取消或关闭窗口不放置模块。地图在预览后发生变化时，旧预览不能应用。

当前采用保守的放置规则：两个模块的完整单元格包围矩形内须为空白，包括稀疏模块的空洞，不能覆盖已有地面、中间层、对象、碰撞或其他单元格内容。连接超出地图、开口失效或地面素材的偶数网格无法对齐时会拒绝预览。单次模块占地总数上限为 1,000,000 格。

本阶段放置的是两个新的对象实例，不能直接选取地图上已有对象来自动扩展模块链。放置后可沿用原有对象拾取功能分别移动两个实例；目前不保存连接网络约束，因此移动后不会自动维持接缝。

## 自动生成模块地图

1. 使用“工具 → 从选区生成模块”制作并入库，或为已有 .X 对象定义并保存连接点。模块池仅列出带已保存连接点的目录对象；普通素材不会自动成为模块。
2. 切换到普通地图，加载素材库并解锁全部图层。可先框选生成区域，再打开“工具 → 自动生成模块地图”。没有选区时默认使用地图中心最多 128×128 格的区域。
3. 勾选参与生成的模块。可选择 1～256 种，程序允许重复使用同一种模块，不需要逐个指定实例或连接点。
4. 填写模块总数量（2～128）、随机种子、区域左上角和宽高，选择布局：
   - **链式**：每次接到最新放置的模块，形成按接口顺序延伸的模块链。
   - **分支**：优先从靠近起点的模块向外展开。
   - **紧凑**：优先使用当前布局中心附近的可用接口。
5. 点击“生成连通布局”。程序自动选择起始模块、位置和后续连接；遇到放不下的组合会回退，并尝试其他模块、接口或起始位置。
6. 检查“地图预览”和“连接示意图”，确认提示中的数量和连通性，再点击“应用到地图”。整次生成是一条撤销记录，地图保存重开后保留全部对象实例。

相同素材文件、连接点、勾选顺序、目标地图、参数、种子和软件版本会复现相同布局。可点击“更换种子”重新生成；种子显示在结果提示中，目前不自动写入地图配方。

生成区域最多 1,000,000 格，模块池的单元格包围矩形总面积最多 4,000,000 格。每个模块的完整占地（包含空洞）须位于区域内、与其他模块不重叠且不覆盖地图原有内容，地面素材继续遵循偶数网格。素材不做坐标旋转或镜像。

自动生成的连通性要求比手动双模块拼接更严格：

- 每个参与模块内部的所有可行走格和接口必须通过上下左右四邻格互通，低／高碰撞和前景阻塞位都会阻断通路。存在内部隔断或孤立可行走小块的模块会被点名拒绝。
- 每个新实例都通过类型、宽度一致且方向相对的接口接入已有布局，同一个接口不会重复使用。
- 完成后再次检查实际生成的单元格：所有生成模块占地内的可行走格必须整体连通。地图外部空白区域不能作为绕路依据，斜对角接触不算连通。

只有达到填写的数量并通过检查，结果才允许应用。素材、区域或搜索尝试不足时会明确提示本轮最多放置的数量，不会提交较少模块的半成品。有限搜索失败不证明绝对无法拼成，可更换种子、扩大区域、减少数量或添加匹配模块后重试。

“停止生成”、取消、关闭窗口或修改参数都不会修改地图；修改参数后旧预览立即失效。生成结果是新的实例集合，不会自动接续地图中已有实例，也不会自动封堵未使用的出口或补绘缺失的墙体。布局策略控制模块的接口连接和放置顺序，不会修补素材自身开放边界；需要封闭房间时，应在模块中绘制相应碰撞。后续手工移动或修改实例后，需要重新检查通路。

## 坐标与校验

- 坐标是 `.X` 对象局部坐标，可以是负数。旧模块边界由所有非空格的包围矩形确定；从选区制作的模块额外保留选区占地，避免边缘空白被裁掉。后续绘制超出原占地时，边界取占地与实际内容的并集。
- 北／南开口从起点向右延伸，东／西开口从起点向下延伸。宽度单位为地图单元格。
- 连接点编号在同一对象内不区分大小写且必须唯一；连接类型为用户定义的标识，例如 `path`、`door`。编号和类型不能空白、带首尾空格或控制字符，长度上限为 64。
- 开口必须在对应边界内，不能重叠；开口和向内一格都必须无碰撞。稀疏对象中没有记录的格子按无碰撞处理。
- 每个对象最多 64 个连接点，每个开口宽度为 1～64 格。这里检查开口附近通路，不代表已经证明模块内部所有入口彼此连通。
- 修改对象形状或碰撞后，保存会再次校验连接点；失效时需要修正或删除，避免保存错位定义。
- 对象保存时会按原有规则裁剪并居中，连接点和选区占地同步平移。地面素材的偶数网格对齐保持不变。

## 存储与当前边界

连接点保存在编辑器 `catalogue/palette.json` 的对应对象记录中；`.X` 文件格式保持不变。移动或分享模块时，应同时携带对应目录记录，仅复制 `.X` 不包含连接点。未保存的修改可随既有恢复快照保存。

目录示例（假设对象边界包含此开口）：

```json
"connections": {
  "version": 1,
  "points": [
    { "id": "north-entry", "x": -1, "y": -2, "edge": 0, "kind": "path", "width": 2 }
  ]
}
```

`edge` 取值为 `0=北`、`1=东`、`2=南`、`3=西`。没有连接点的旧目录记录仍可读取；删除全部连接点会保存空的 `points` 数组。

从选区制作的模块还会在 `connections` 下写入可选的 `footprint`，例如 `{"x":-4,"y":-4,"width":8,"height":8}`。它只声明占地，不增加虚构的地砖或碰撞；旧记录无需迁移。分享时应使用支持此字段的版本，并携带目录记录，单独复制 `.X` 无法保留空白边距及接口。

目前已实现双模块拼接和带整体连通性验证的自动模块生成。后续可增加连接网络持久化、已有实例接续和自动出口封闭。图片旋转／镜像需要相应美术变体，不能只旋转坐标。

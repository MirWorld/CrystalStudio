# 快速创建地图实施计划

目标：依次统一尺寸限制、整合快速创建、闭合保存流程、复用生成参数并提供独立恢复快照。

架构：保持现有 Crystal 地图和素材格式，复用三个生成器的预览与应用。恢复文件放入配置目录，不自动覆盖正式地图。不新增依赖、不更改生成算法、不提交 Git、不创建分支，新增界面同时提供中英文。

## 实施及验证
1. 添加 MapCreationTests，统一 MapDimensions 在构造、读取、保存、新建及生成模式的限制。验证 4096 平方被拒绝、合法小文档保持兼容。
2. 新增 NewMapWindow 与 MainWindow.MapCreation；快速创建先选类型，再进入现有生成预览。取消不创建标签；无素材可创建空白地图。
3. 新建可命名及选择目录，默认客户端 Map。禁止静默覆盖；保存失败保留文档；成功刷新并定位地图列表。
4. 保存上次配置及命名预设，复用生成窗口完整参数。独立配方记录种子、参数、素材路径及格式、生成器版本。
5. 增加独立定时恢复快照、启动提示和恢复入口。恢复为未保存副本；明确保存或丢弃后清理；单个损坏快照不阻止其他恢复。
6. 先运行新增测试确认失败再通过，再运行完整回归和 Release 构建；更新 README，明确真实素材及 GUI 验收边界。

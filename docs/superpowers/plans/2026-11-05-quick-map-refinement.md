# 快速创建地图：第二轮细化

## 已批准范围

1. 在昂贵的地图规划前检查选中风格的必要地面/墙体；分别展示必要缺失和可选缺失。省略缺失的可选河流、海岸、悬崖、植被、城镇，不把它们误报为整张地图不可创建。
2. 预览持续展示地图名、类型、尺寸、保存方式、完整输出路径、预设及生成提示。覆盖同名预设只在最终创建时确认；取消确认留在预览。空白地图仍在其最终创建入口确认。
3. 当前创建会话最多保留五个候选，保存种子、参数与小缩略图，不持有额外完整地图。收藏防止被自动淘汰；五个均收藏时提示先取消收藏。候选恢复重新生成，尺寸/类型不匹配时不可恢复；视图切换不增加候选。
4. 预览提供鼠标滚轮缩放、拖动、按钮/键盘操作、复位和双击指定位置的局部重绘。明确区分预览图放大与局部重新渲染，不声称总览放大达到原始精度。

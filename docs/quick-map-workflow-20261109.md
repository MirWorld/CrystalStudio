# 快速创建地图：专业制图工作流优化

日期：2026-11-09。

本轮不新增地图类型，也不替换生成算法。重点是让设计人员直接表达意图、保留已确认结构、继续未完成工作，并识别过期的检查结论。

## 1. 预览中的设计编辑

- 预览工具包含平移、选择、关键点、净空、保护和通行区域。
- 选择工具支持拖动关键点或区域；区域右下角拖动缩放。
- 坐标列表与图上选择相互同步，路线编号和角色标签可见。
- 中键平移；方向键微调，Shift 每次移动 10 格；Esc 取消未提交手势。
- Ctrl+Z / Ctrl+Y 以及工具栏按钮撤销、重做设计标记。历史最多 100 步，与地图格子编辑历史隔离。
- 更新预览期间可以继续在保留的预览上编辑标记，触发新一轮计算；旧预览不能被创建。
- 坐标换算使用生成窗口实际显示区域，覆盖总览、局部细节以及原生预览的留白。

## 2. 可操作的检查问题

- “生产工具与种子搜索”增加“检查当前布局”和问题列表。
- 问题保留必需/偏好性质、条件名称、坐标和原因。
- 选中问题后可定位、放大，并选中对应标记或区域进入调整。
- 地图预览、设计条件或装饰输出变化后，旧检查结果失效，不能作为新的通过结论。
- 检查不会自动放宽必需条件；创建前仍使用当前实际输出重新校验。

## 3. 锁定布局，生成受控装饰变体

- 在“受控装饰变体”中锁定已经确认的布局。
- 结构参数、主种子、随机设置、设计标记和候选切换被冻结；缩放、平移仍可使用。
- 用户逐类勾选允许移动的原生物件，默认不勾选。非阻挡不能自动等同于装饰。
- 只移动图中已经存在的完整物件，不引入新素材、不拼接残缺物件，不增加物件数量。
- 排除墙体、生成河岸、碰撞修改、所有权不完整或重叠、已被手工修改的物件。
- 原始位置和目标位置都避开设计区域、关键点及净空缓冲；目标需要空闲且地表与源位置一致。
- 最多移动 256 个物件，每个物件最多尝试 64 个位置；找不到安全位置保留原样，明确报告零变化。
- 使用 SHA-256 复核整图地表、碰撞、地表动画、门和光照等锁定数据，再检查必需布局条件。
- 对照开关仅改变显示，不改变将要创建的输出；显示原始布局时会明确提示这一点。
- 修改装饰种子或允许类型后，旧变体丢弃，回到锁定基线，需重新生成。
- 停止或关闭窗口不会提交尚未完成的变体；解除锁定有丢弃变体的明确确认。

## 4. 创建任务草稿

- 使用用户配置目录中的独立 `quick-map-draft.json`，不自动写入地图文件。
- 稳定状态下延迟约 750 毫秒保存，并提供手动保存；关闭时保存稳定任务状态。
- 每个配置目录保留一个最近任务，包含参数、设计标记、收藏、当前候选、A/B 选择和锁定/变体配方。
- 候选最多五个，图片保留有界快照；文件上限 16 MiB。验证或保存失败时保留上一份草稿。
- 起始设置页提供“继续上次创建任务”；恢复后关闭立即保存，结果始终先作为未保存新地图。
- 恢复时比较生成器版本、目录 SHA-256 及素材库版本身份。库身份沿用现有路径、大小、修改时间，不等同于库内容全量哈希。
- 版本不一致时，需确认才恢复参数、标记和收藏配方；不恢复旧图片或变体。
- 即使版本一致，也不恢复候选检查指标作为有效结论。恢复候选后仍要重新生成、检查。
- 装饰变体根据原始布局配方、允许类型和装饰种子重建；缺少类型时不静默退回基础地图，必须明确选择放弃。
- 完成已保存或恢复的当前任务后清理对应草稿；直接创建其他空白地图不会删除未使用的旧任务。

## 5. 轻量设计意图

- 关键点可标记为普通、入口、目标或出口，不生成 NPC、任务或服务器实体。
- 每个点可选择净空半径，0 表示关闭。
- 顺序路线可以设置最小/最大路径格数，0 表示不限制；不将格数解释成游玩时长。
- 可选“到出口前必须穿过目标占地区域”，用实际碰撞及角色占地检查是否存在绕过目标的路径。
- 目标穿越需要恰好一个入口、目标、出口，只判断空间瓶颈，不等同于任务完成检查。
- 意图检查默认关闭，启用后可选偏好或必需；非法范围或角色配置会明确拒绝，不自动忽略。
- 设计角色不重排路线，顺序仍由关键点列表决定。

## 6. 创建后的编辑衔接

- 新地图携带设计标记、生成配方和装饰变体来源。
- “地图生产工具”增加“创建交接”：显示来源、检查是否过期及未满足条件。
- 可以与创建初始状态对照，分别统计地表、装饰和碰撞变化；列表最多展示 1,000 个位置，并支持定位。
- 有素材时显示基线与当前地图的同步缩放/平移图像。
- 对照不会应用修改；重新分析后更新最新检查状态。
- 创建基线保存在当前打开地图标签的内存中，不随保存写入地图；关闭再打开后不提供该次会话基线。配方和设计标记仍使用既有旁置文件。

## 兼容性和验证边界

- 不修改 `.map` 格式；角色和意图仍在编辑器设计元数据中。
- 新流程来源附加 `/workflow-v1`，独立于 v1/v2/v3 生成算法版本。
- 旧配方缺少新字段时保持默认行为；旧算法的地图格子基线需要继续通过回归测试。
- 自动化测试包含模型不变量、草稿往返、原图保护、实际鼠标手势、问题定位、配方恢复/拒绝回退、中文与英文 Headless 界面渲染。
- 界面截图使用测试素材库，不能证明真实客户端素材的接缝、遮挡或地图可玩性。
- 尚需真实地图编辑人员执行同一组任务的耗时/误操作对照，以及实际客户端中的通行和视觉验收。

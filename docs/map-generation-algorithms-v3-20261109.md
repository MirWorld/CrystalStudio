# 自动地图生成：统一占地与实图验收

日期：2026-11-09。

本轮对应五项建议：统一占地和可达性、实际行走距离补环、可操作的失败诊断、有质量与差异的候选保留，以及原生素材独立验收。没有增加地图类型、全图 WFC、服务端实体或自动挖路功能。

## 版本与兼容

- 全新且未恢复旧配置的生成窗口，以及内置模板，默认使用“实图验证算法 v3”。
- v1、v2 均保留。旧配方的版本字段按原值恢复；没有版本字段时仍按 v1 处理，不能静默升级种子结果。
- v3 只为普通经典地牢新增实图补环选择；主题地牢、洞穴和其他 v2 策略沿用原有构造。生成器公共 API 的选项默认仍是 v1。
- 新配方写入 `Parameters.AlgorithmVersion = 3`，并带 `/algorithm-v3` 标识。地图格式、创建/保存/撤销流程不变。
- 设计设置新增 `FootprintSize`，旧 JSON 缺少此字段时默认 1。它参与设计复制、比较、候选身份、配方与编辑器元数据，不属于仅供预览的临时设置。

## 1. 同一占地、同一可达性口径

方形边长为 1–64 格，路线点与通行区域中的位置均按占地左上角锚点解释。通行区域为一组锚点，其占地可能延伸到区域右侧和下侧，但不能越出地图。

- v2/v3 在装饰前预留完整占地：通行区域扩展至全部覆盖格；必需路线预留完整扫掠区域及一格缓冲，不使用绘图采样路径代替实际路线。
- 生成约束、路线分析、批量指标与创建前复核使用相同边长，同时检查两种原生碰撞位和地图边界。
- v1 保持旧布局序列，仅在生成后用所选占地检查结果，不改变旧算法的随机过程。
- “可通行比例”的分母是地图内能够放下占地的锚点总数，不是原始格数；因此空地图在 2×2 占地下仍能达到 100%。
- “可达比例”在设置路线点时，以第一个点所在的连通区为分子；没有点时才使用最大连通区。分母均为可通行锚点总数。
- “狭窄格”按所选占地锚点图的邻格连接度统计，不等同于通道几何宽度。路线未设为必需时，界面明确提示可达性结果不阻止创建。
- 清物件区不等于可通行区；保护区仍只影响局部生成。没有增加斜向移动、旋转角色、动态障碍或服务端移动模拟。

## 2. 用最终原生碰撞图决定普通地牢补环

v2 的无权房间图算法保留不动。v3 先生成不含额外回路的完整原生地图，再计算各房间锚点之间的实际四向路径格数。

候选连接先按预计节省距离排序，但估价只决定尝试顺序，不能作为接受证据。每次尝试重新完成原生墙体、地表及约束检查，然后在实际碰撞格上复核：

1. 原先可达的房间锚点必须仍全部互通。
2. 所有房间对的最短路径总格数必须严格减少。
3. 以原图中固定的一对最远房间锚点作为参考主干，其距离不能短于原来的 75%。
4. 无法按所选占地复核房间锚点时，保留原骨架，不声称验证成功。

每张地图最多尝试 6 次候选连接，外加一次原骨架生成；取消检查贯穿生成与 BFS。预算耗尽不代表不存在其他可行连接。界面报告实际尝试数、保留回路数和参考主干前后格数。

这是有限贪心选择，不保证全局最优，也不将格数解释为玩家通关时间。真实碰撞复核有额外成本，不承诺比 v2 更快。

## 3. 区分条件矛盾、种子失败与预算耗尽

诊断保留阶段、原始原因、相关条件名称和坐标，并给出不同的下一步操作：

| 分类 | 含义 | 搜索行为 |
| --- | --- | --- |
| 输入条件冲突 | 如必需占地越界、与永久封闭边界相交 | 停止无效重试，要求调整条件 |
| 当前种子未通过 | 如当前水岸/墙体不满足路线，或种子相关边界侵入预留区 | 继续尝试下一种子 |
| 缺少必需素材 | 素材预检确认必需资源不可用 | 停止重试，提示恢复素材或改用受支持风格 |
| 搜索预算耗尽 | 指定尝试次数内没有匹配结果 | 不宣称不存在可行布局 |
| 未预期错误 | 不能可靠归入上述类别 | 停止并保留种子、参数及原始错误 |

省域边界的厚度随种子变化，不能把所有边界冲突都说成“换种子无用”。只有必然封闭的最小边界带属于永久矛盾；可变边缘按当前种子失败处理。边界冲突列出用户条件及封闭边界条件，但不冒充全局最小不可满足集。

数值筛选失败会显示实测值与目标阈值。必需条件不放宽，偏好条件仍只警告。

## 4. 候选按质量与差异保留

搜索仍连续尝试 2–10 个种子，保留容量仍为五个，收藏不被淘汰，不自动应用地图。

- 仅合格结果参与测量候选保留；普通手动预览的候选行为保留。
- 相同尺寸、设计快照和占地口径下，使用 SHA-256 通行布局指纹识别重复。不同纹理但通行布局相同的种子仍完整列在搜索结果中，可手动恢复。
- 质量比较考虑偏好冲突数、起点覆盖率和路线段可达率；不将路线越长或地图越空泛化为质量越高。
- 布局差异描述包括路线长度、平均尽头支路深度、平均方形净空、可通行比例、尽头密度和房间数；在固定容量中比较最近邻差异。
- 不同设计条件下的指标不直接比较；无法比较的未收藏旧候选可被新的实测候选替换。
- 无需保留的新结果会解释重复或质量/差异原因。当前预览未进入候选池时，不误高亮其他种子，也不会伪称已保留。
- 实测的 v1 候选同样保存其评估设计快照；恢复时恢复评估口径，但仍执行 v1 布局算法。

这是可解释的有界保留策略，不是完整 MAP-Elites，也不保证任何审美指标最优。

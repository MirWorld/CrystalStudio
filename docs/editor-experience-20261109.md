# 编辑器交互优化（2026-11-09）

## 范围与边界

本轮落实 `Build/Reviews/editor-design-20261109/review.md` 的九项建议。保留生成与拆分算法、随机参数范围、资源支持、文件格式、覆盖确认及撤销单位；不新增主路线规划、局部地图重生成或自动修复通行区。

## 已实现

1. **编辑上下文**：工具、目标层、可见性、锁定、素材和作用范围常驻状态栏，不依赖左侧当前页签。自动退回铅笔给出原因；增大图层锁定控件的点击区域。
2. **悬浮检查**：450ms 停留延迟，默认仅坐标/通行性，按 Alt 查看详情，绘制和拖拽时收起；保留空心预选框及边界避让。
3. **快速创建**：小窗口保留名称、尺寸与保存摘要，完整目录放在摘要提示中；尺寸、名称、输出目录与预设字段有就地错误，可定位首个错误。
4. **资源诊断**：统一等待、检查、生成、就绪、失败阶段。默认呈现必需缺失与可选不可用数量，展开查看目录条目、实际库文件、加载根目录及格式，并优先展示安全恢复步骤。已加载但目录图片不匹配不再只有内部编号。可选资源晚到不会将过期预览标为可应用。
5. **模块拆分**：常驻显示可用/选中数量、模块类型分布、选中接口及相对方向匹配状态，长说明折叠。匹配状态只表示存在兼容接口，不承诺所有模块都能组成布局。
6. **模块生成**：显示请求/实际数量、独立类型、复用次数、连接及已连接接口数。最近五组成功参数仅在本次窗口内保留，可恢复并重新生成；不缓存多张完整地图。已连接接口不是尚未使用的接口，原有封口与连通性检查保留。
7. **目标区分**：普通生成器明确“应用到当前地图”，快捷创建明确“创建新地图、不修改原地图”，不改变实际写入语义。
8. **资产语义**：本地别名与资源文件身份关联，同编号不同文件的别名不混用；兼容原收藏/最近使用记录。原始库按别名或编号检索，已用筛选按当前地图、图层和素材库匹配，地图变化后更新。原有文件来源提示、分类和吸管反查保留。
9. **撤销与保存**：历史动作名称跟随原有撤销/重做和文档快照，不改变提交边界。分别显示本次会话的文件保存与恢复快照时间，快照失败保留警告；快照成功不清除未保存标记。显示的是最后成功写入时间，不承诺旧快照仍存在（手工保存后沿用原规则清理快照）。

# 地图生产功能增强 · 2026-11-09

## 范围与入口

本轮针对配方恢复、指定目标路线分析、批量候选筛选、区域约束、保护式局部生成、地图交付包六个方向增加独立功能。保留原有生成算法、默认参数范围、地图和素材格式、保存覆盖确认以及撤销提交规则；新能力默认不参与旧生成流程。

- 主入口：工具 → 地图生产工具。
- 种子搜索与创建约束：快捷创建预览 → 生产工具与种子搜索。
- 独立导出入口：文件 → 导出地图交付包。

## 实现行为

### 1. 配方恢复

支持查看当前地图的生成来源，也可打开 `.creation.json`。校验版本、类型、尺寸、参数上限和设计标记，再进入原有创建设置页。首次设置页优先使用配方参数而不是上次生成器参数。默认建立新的未保存地图，不覆盖旧图。

比较生成器版本、素材来源格式、已记录目录散列和已加载素材库身份；控制项恢复时如有参数调整，会在预览中显示差异。素材库身份由路径、文件长度、修改时间构成，不是完整素材内容散列。配方只记录部分目录，不能据此承诺全部依赖未变或完全复现，更不能恢复手工成果。

### 2. 有序路线分析

最多 32 个点，按列表顺序检查相邻点之间的四方向最短路线。报告可达性、格数、曼哈顿绕行倍数、最多两个可通行邻居的格数及最多一个邻居的格数。重合点为零步；阻挡端点和无路段不产生虚构路线。

沿用 `BackImage & 0x60000000` 的碰撞判断，空地未额外推断为不可通行。它不验证游戏客户端规则、怪物行为、角色净宽、门开关策略或实际游玩时间。分析最多 4,000,000 格，支持取消；路径绘图限量抽样，不缓存完整大图路径副本。局部生成改变地图后，旧路线结果失效。

### 3. 约束和批量筛选

最多 64 个区域：保护区仅作用于局部生成；净空预留检查中间层、前景锚点、门和已记录物件占地；通行走廊要求范围内碰撞格可通行。有序路线可设为必需。硬约束不通过则不创建，软约束不通过须明确确认继续。

这是有上限的生成结果验证与拒绝采样，不是自动雕刻道路、固定城镇布局或自动修复通行区。净空约束不声称覆盖全部图像外伸。不能满足时会保留具体原因，不忽略硬约束。

批量从当前有符号整数种子依次递增，溢出按整数循环，单批 2–10 个。每个种子顺序生成、测量、过滤后才继续下一项，保留实际指标和失败原因。没有不透明的总评分。连通占比的分母是所有可通行格，而不是所有地图格；房间阈值仅用于地牢。

完整地图结果不组成多图缓存。原候选上限仍为五组，快照仍有既有像素上限，收藏不被淘汰。没有匹配或全部收藏时给出说明，未保留快照的搜索条目仍可恢复参数重新生成。停止保留完成项，不自动应用任何结果。

### 4. 保护式局部生成

先在主地图选择区域；源布局生成到隔离文档。随后按选区及保护区域合成，并在同步缩放的前后视图中再次确认，最后提交一次撤销。期间不写工作地图；拒绝过期预览，遵守图层锁。

- 保留两格边界、原碰撞及全部已有物件的记录占地。
- 地表仅修改完整 2×2 地块锚点的视觉字段和地表动画；任一格受保护时不替换该地块。
- 装饰是安全增补，不是任意擦除重铺：只接纳完整、已记录、无地表或碰撞变化的物件，且其全部锚点空闲。
- 跳过跨边界、跨保护区、相互重叠、不完整、包含地表/碰撞变化的物件，以及墙、河岸和海岸。无记录的孤立素材不尝试裁切粘贴。
- 新物件保存正确的装饰源单元格与前后所有权；不会把背景地表或原碰撞错误认领为可搬移物件的一部分。
- 预览应检查不同材质的接缝和视觉外伸；边界保留并不等于自动无缝拼接。地形生成器不提供完整装饰增补，请选择省域或地牢。

### 5. 交付和持久化

ZIP 在临时文件完整生成后原子替换。地图、小地图和检查来自同一输入副本；未保存修改明确确认。不保存或覆盖工作地图，不把导出当作地图文件保存。支持取消，取消不替换已有 ZIP。

包内包含 `map.map`、`map.map.studio.json`、可用时的 `map.map.creation.json` 和 `minimap.png`、`report.json`、说明文件。不打包 `.lib`。未加载素材时仍可导出地图和报告，但不生成小地图，且图片引用验证标记为未执行。报告保留问题总数、截断状态、资源引用、库身份和包内文件 SHA-256；报告自身不自包含散列。配方尺寸可能保留编辑前的来源尺寸，报告明确标记与副本是否一致。

配方库目录清空，资源身份路径只保留文件名、长度和修改时间；不自动上传诊断、本机路径或素材。地图自身内容与用户填写的物件/标记名称保持不变，不宣称对任意用户文本完成了隐私审查。

编辑器设计标记在地图保存时写入版本 1 `.studio.json`，并进入恢复快照。当前设计与配方里的原始约束分别维护。标记改变使地图显示未保存；标记自身不进入绘制撤销栈。坐标不会在裁剪、扩边后自动猜测迁移，失配标记需人工修正；保存失败保留未保存提示。
